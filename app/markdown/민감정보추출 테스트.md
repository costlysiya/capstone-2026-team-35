# 개인정보 자동 탐지 모델(하이브리드 매칭)의 한계점 및 향후 고도화 방안

## 1. 개요 및 개선 완료된 시스템 성과

본 프로젝트는 사용자 데이터의 완벽한 프라이버시 보호를 위해 기기 내부(On-device)에서 민감 정보를 선제적으로 탐지하고 암호문(`[ENC:...]`)으로 치환하는 종단간 암호화(E2EE, End-to-End Encryption) 파이프라인을 구축하였다. 

초기 단순 정규표현식(Regular Expression) 기반 탐지의 한계를 극복하고자 **'하이브리드 키워드 매칭(Hybrid Keyword Matching)'** 알고리즘을 고도화하여 적용하였으며, 이를 통해 도출된 주요 성과는 다음과 같다.

*   **탐지 유연성 및 커버리지 확대:** 주민등록번호(내/외국인 전체 체계 대응 및 하이픈 누락 방어), 14~16자리 신용카드 번호 등 비표준 규격을 포괄적으로 감지할 수 있도록 정규식 체계를 확장하였다.
*   **오탐지(False Positive)의 획기적 감소:** 추출된 숫자 주변의 문맥 키워드(예: '카드', '은행', '원' 등) 배열을 교차 검증하여, 단순 상품 바코드나 무의미한 일련번호가 민감 정보로 오인되어 과잉 마스킹(Over-masking)되는 현상을 차단하였다.
*   **LLM 구조화 프롬프트 튜닝 연동 완료:** 기기에서 전송된 암호문(`[ENC:...]`)을 서버 측 대형언어모델(LLM)이 무의미한 데이터로 취급해 누락시키는 문제를 해결하기 위해, LLM System Prompt를 최적화하였다. 이를 통해 LLM은 암호문을 개인정보 메타데이터로 정확히 인지하여 반환하며, 클라이언트(앱) UI 계층에서 이를 안전하게 복호화하여 사용자에게 완벽하게 구조화된 정보를 제공할 수 있는 이상적인 보안-편의 파이프라인을 완성하였다.

---

## 2. 현재 하이브리드 탐지 모델의 기술적 한계

위와 같은 고도화 작업과 서버 측 프롬프트 개선을 통해 실무 적용이 가능한 수준의 방어력을 갖추었으나, 텍스트 분석 알고리즘의 구조적 특성상 다음과 같은 한계점이 여전히 존재한다.

### 2.1. 극단적 비표준 텍스트에서의 문맥 유추 실패 (False Negative)
하이브리드 매칭은 과도한 오탐(False Positive)을 막기 위해 필수적으로 주변의 '지정된 키워드'를 요구한다. 그러나 이미지 내에 "카드"나 "신용" 등의 단어가 일절 포함되지 않은 상태에서 15자리의 아멕스 카드 번호만 단독으로 기재된 경우, 시스템은 이를 일반적인 숫자로 보수적 판정을 내려 마스킹을 누락할 위험성을 내포하고 있다.

### 2.2. 자연어 구문 기반의 심층적 의미 론(Semantics) 추론 부재
현재 모델은 텍스트 내 특정 단어의 '존재 유무'를 검사할 뿐, 문장 전체의 형태소 구조나 뉘앙스를 추론하지 못한다. 예를 들어 "여기에 적힌 내 식별 코드는 1234..."와 같이 사전에 등록되지 않은 자연어 문맥으로 개인정보가 주어질 경우, 룰 기반(Rule-based) 탐지의 사각지대에 놓이게 된다.

### 2.3. 규칙 기반(Rule-based) 엔진의 유지보수 오버헤드
금융 기관의 새로운 번호 체계 도입, 글로벌 서비스 확장에 따른 해외 여권 규격 변화 등 외부 요인이 발생할 때마다 정규식과 키워드 사전을 개발자가 수동으로 업데이트해야 하는 관리적 비효율성(Hard-coding Overhead)이 존재한다.

## 3. 향후 고도화 방안 및 결론

현재의 규칙/키워드 혼합 방식을 넘어, 오탐과 누락률을 0%에 가깝게 수렴시키고 시스템의 확장성을 확보하기 위해 다음과 같은 차세대 딥러닝 기술의 도입을 향후 과제로 제안한다.

### 3.1. 온디바이스 기반 초경량 NER(개체명 인식) 모델 전면 탑재
*   **개선 방안:** 키워드 사전과 정규식에 의존하는 탐지 로직을 점진적으로 폐기하고, 문장 전체의 맥락을 스스로 이해하는 초경량 머신러닝 언어 모델(Tiny-BERT, MobileBERT 등)을 앱 내부(On-device)에 탑재한다.
*   **기대 효과:** NER 모델은 특정 키워드가 존재하지 않더라도 문장의 형태소 배열을 분석하여 해당 문자열이 개인정보일 확률(Confidence Score)을 자체적으로 산출한다. 이는 예외적인 입력 포맷에서도 높은 정확도를 보장하며, 정규식 업데이트 없이 모델 재학습만으로 유연한 대처가 가능하게 한다.
*   **데이터 프라이버시 유지:** 추론 연산이 서버를 거치지 않고 사용자 기기 단말(Edge AI)에서 독립적으로 수행되므로, 기존 프로젝트의 핵심 가치인 '민감 정보 제로 전송(Zero Data Leakage)'의 보안 원칙을 훼손하지 않으면서 탐지 성능만을 비약적으로 상승시킬 수 있다.
